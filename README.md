# esepx.kz

Сайт ESEP — автоматизация для бизнеса и бухгалтеров.

Всё, что лежит в этом хранилище, автоматически публикуется на https://esepx.kz
(hoster.kz → Plesk → Git, папка httpdocs).

- `index.html` — главная страница.
- `brand.css` — дизайн-система ESEP для страниц сайта: цвета обеих тем, шрифты, кнопки, фирменная полоса. Основной логотип — в круге (`img/esep-logo-ring.png`, `@3x`); SVG-версии без круга (`img/esep-gradient.svg`, `esep-purple.svg`, `esep-white.svg`) — запасные.
