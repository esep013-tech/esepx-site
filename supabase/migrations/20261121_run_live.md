# 21.11.2026 — живой ход запусков, остановка, продолжение

robot_runs: beat (пульс), now_firms (на какой фирме сейчас), cont (сколько раз продолжали), tries jsonb (сколько раз брались за фирму).
- `public.run_cancel(p_id)` — остановить (админ, кто запустил, владелец/главбух/сопровождение/оператор фирмы запуска; `private.run_can`).
- `public.run_resume(p_id)` → `private.run_resume_kick` — pg_net POST robot-1c {run_id, resume:true}.
- `private.run_watchdog()` — cron `server-runs-watchdog` каждую минуту: серверный запуск без пульса 2 мин — Дт/Кт продолжается (до 60 раз), другие закрываются с ошибкой.
- `run_progress` отдаёт now, beat, stale (нет пульса 3 мин), can, note, executor.
robot-1c (Дт/Кт): одна фирма — один вызов функции (лимит процессорного времени), дальше вызывает себя; фирма, на которой функция обрывалась дважды, уходит в ошибки.
robot-1c выкладывается загрузчиком: index.ts = import raw.githubusercontent.com/esep013-tech/esepx-site/<коммит>/supabase/functions/robot-1c/index.ts.
