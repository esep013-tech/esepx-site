# Правила для работы с кабинетом ESEP

## Справка ИИ-помощника
Помощник в кабинете (функция `supabase/functions/assistant`) знает устройство сайта только из константы `GUIDE` в этом файле.
- Добавляешь или меняешь раздел, страницу (адрес после #), заметную кнопку, робота или права — в той же работе поправь `GUIDE` и выложи функцию `assistant`.
- Команда Жанны «обнови справку помощника» — полная сверка `GUIDE` с `cabinet/index.html`; порядок действий — в документе проекта `cabinet/ai-assistant.md`.
- Новые данные для ответов добавляются в `context()`; логины, телефоны, почту, номера счетов, адрес 1С и Chat ID в модель не передавать.

## Сообщение об обновлении
Помощник один раз говорит каждому пользователю, что кабинет обновился, и коротко — что изменилось.
- При каждой выкладке изменений кабинета, заметных пользователю: поставь новую версию (дата + номер, например `2026-11-20.1`) сразу в двух местах — константа `APP_VER` в `cabinet/index.html` и поле `v` в `cabinet/version.json` — и перепиши `notes`: 1–5 коротких строк простым языком, что изменилось и где это найти.
- В той же выкладке допиши те же строки в `cabinet/changelog.json` — это страница «Что нового» (#news): записи по датам, свежая дата сверху; если запись за сегодня уже есть, добавь строки в её начало, а не создавай вторую.
- Строки только для администратора ESEP (раздел «Управление», запуск роботов, служебные настройки) начинай с `(админ) ` — обычным пользователям кабинет их не показывает (решение Жанны 26.11.2026). Строки со ссылкой `(#admin/…)` и со словами «Управление →» скрываются от пользователей сами. Пользователям пиши только то, что они увидят у себя.
- В строках `notes` и `changelog.json` давай ссылку на место в кабинете в виде `[текст](#адрес)` (например `[«Реквизиты»](#req)`) и коротко — где нажать; другой разметки не использовать.
- После push дай сигнал открытым кабинетам (проект Supabase esep-cabinet): `update public.app_version set v = '<та же версия>', at = now() where id = 1;` — кабинет получит его по живой связи и сверится с `version.json`. По таймеру кабинет обновления не проверяет.
- Версии должны совпадать, иначе пользователю будет предлагаться обновить страницу, которая уже свежая.
- Чисто внутренние правки (серверные функции без видимых изменений) версию не меняют.

## Оформление
- Во всём кабинете (все разделы, отчёты на экране и печать) таблицы и сводки выравниваются по левому краю — и текст, и числа, и заголовки столбцов (решение Жанны 20.11.2026). По правому краю или по центру — только если она сама попросит.
- Без внутренних бегунков: списки и таблицы внутри страницы показываются целиком, без своей прокрутки по высоте (`max-height` + `overflow`) — прокручивается сама страница или окно (решение Жанны 26.11.2026). Исключения — только критичные случаи: широкие таблицы вбок (как «Реквизиты»), переписка (помощник, чат задачи), панель задач и меню.
- Сам кабинет прижат к левому краю окна, а не стоит посередине: слева меню (`#nav`, 216 px), сразу за ним страница — `.in{margin:0}`, `--tk-off` = ширина меню (на экране уже 900 px меню выезжает по ☰ и `--tk-off` = 0). Форма входа остаётся по центру.
- Основной логотип ESEP — знак в круге: `img/esep-logo-ring.png` (`@3x` для Excel и печати), в письмах — `img/esep-mail.png`. Он стоит везде: сайт, кабинет в обеих темах, печать, PDF, Excel, письма (решение Жанны 24.11.2026). Остальные версии из дизайн-системы (`img/esep-gradient.svg`, `esep-purple.svg`, `esep-white.svg` — надпись без круга) — вспомогательные: ставить только если она сама попросит.
- Скругления в кабинете — как до 24.11.2026: кнопки, вкладки, переключатели и метки полукруглые (`999px`), карточки и окна 16–24 px, поля ввода 10 px. Главная кнопка, выбранные фильтры и счётчики — с градиентом в обеих темах (решение Жанны 24.11.2026). Новое от дизайн-системы остаётся: шрифт Montserrat, цвета тёмной темы, полоса сверху.
- Письмо-приглашение (`supabase/email/invite.html`) — прежний вид, не менять без её просьбы.
- Светлая тема — прежние цвета (`theme.css` для кабинета, `brand.css` для сайта); тёмная — цвета дизайн-системы ESEP (решение Жанны 24.11.2026).
- Главная (#home) отвечает на вопрос «что сделать сейчас»: счётчики, предупреждения о долгах ЛС и пороге НДС, список «Требует решения» — выше всего остального (решение Жанны 24.11.2026). Тёмная и светлая темы остаются обе.
