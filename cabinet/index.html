Налоговая отчётность

Робот проверяет в кабинете налогоплательщика, приняты ли эти отчёты, пока идёт срок сдачи.

Подробнее

Какие налоговые отчёты сдаёт фирма. Список заполняется сам по профилю: плательщик НДС — 300; ОУР и упрощёнка с работниками — 200; упрощёнка — 910; ОУР: ТОО — 100, ИП — 220. Остальные (700, 851) добавьте вручную; лишний — уберите. Робот мониторинга проверяет в кабинете налогоплательщика («Мои документы»), приняты ли отчёты, — по понедельникам, только пока идёт срок сдачи. В неделю срока уплаты налогов (25 число второго месяца после квартала/полугодия, 10 апреля — по годовым) проверка переносится на этот день и робот заодно запрашивает лицевой счёт.

Запустить робота сейчас

Кнопка сразу запускает процесс в UiPath Orchestrator — без открытия Assistant.

Нужно один раз подключить UiPath к кабинету:
  1. cloud.uipath.com → Admin → External Applications → Add Application → «Confidential application», название «ESEP кабинет».
  2. Add scopes → Orchestrator API Access → Application scope(s): OR.Jobs, OR.Execution.Read → Save (вкладка Application scope(s), не User scope). Скопируйте App ID и App Secret.
  3. Orchestrator → папка с процессами → Manage access → Assign account/group → выберите приложение «ESEP кабинет», роль Automation User.
  4. supabase.com → проект esep-cabinet → Edge Functions → Secrets → добавьте UIPATH_CLIENT_ID (App ID) и UIPATH_CLIENT_SECRET (App Secret).

Уведомления в Telegram
Как узнать Chat ID ▾
Свой (личный чат):
1. Откройте в Telegram бота ESEP — @buh_esep_bot — и нажмите «Старт». Без этого бот не сможет вам писать.
2. Откройте бота @userinfobot и нажмите «Старт» — он пришлёт строку Id. Это число и есть ваш Chat ID, например 123456789.
Группы (чат с клиентом):
1. Добавьте бота ESEP (@buh_esep_bot) в группу как участника.
2. Откройте группу в Telegram в браузере (web.telegram.org): в адресной строке после знака # стоит число с минусом, например -1001234567890. Это Chat ID группы — копируйте вместе с минусом.
Проверка: сохраните и нажмите «Прислать тестовое сообщение» (у получателя — «Проверить чат»). Отправка через бота бесплатная.

Сюда приходят отчёты по кнопке «В Telegram» в отчётах роботов.

Получатели уведомлений

Кому, по каким фирмам и как присылать сообщения роботов: сразу или сводкой утром и вечером. Получатель — ваш Telegram, чат с клиентом или группа; бот ESEP должен быть в этом чате. Как узнать Chat ID — в подсказке выше. В группе фирм новые фирмы подхватываются сами.

Открывать 1С

Сохраняется сразу. Действует только на этом компьютере и в этом браузере. Логин и пароль 1С всегда спрашивает сама 1С — кабинет их не знает.

Чтобы браузер мог запускать программу 1С, один раз установите помощник на этом компьютере (Windows, 1С:Предприятие уже установлена):
  1. Скачайте помощник (браузер может предупредить о файле — выберите «Сохранить»).
  2. Откройте скачанный файл двойным щелчком — появится «Готово».
  3. Нажмите ↗ у любого документа: браузер спросит разрешение — отметьте «Всегда разрешать» и «Открыть».
Помощник ставится только для вашего пользователя Windows и умеет одно: запустить 1С по ссылке из кабинета. После установки скачанный файл можно удалить — помощник сохраняет свою копию. Чтобы обновить помощник, скачайте и откройте файл ещё раз. Удалить: Win+R → wscript "%LOCALAPPDATA%\ESEP\esep-open-1c.js" /remove
