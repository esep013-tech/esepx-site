Профиль фирмы

Налоговая отчётность

Робот проверяет в кабинете налогоплательщика, приняты ли эти отчёты, пока идёт срок сдачи.

Подробнее

Какие налоговые отчёты сдаёт фирма. Список заполняется сам по профилю: плательщик НДС — 300; ОУР и упрощёнка с работниками — 200; упрощёнка — 910; ОУР: ТОО — 100, ИП — 220. Остальные (700, 851) добавьте вручную; лишний — уберите. Робот мониторинга проверяет в кабинете налогоплательщика («Мои документы»), приняты ли отчёты, — по понедельникам, только пока идёт срок сдачи. В неделю срока уплаты налогов (25 число второго месяца после квартала/полугодия, 10 апреля — по годовым) проверка переносится на этот день и робот заодно запрашивает лицевой счёт.

Новые пользователи

Фирмы клиентов

Ключи для роботов

Ключ нужен роботу (UiPath), чтобы брать список фирм и писать сообщения в кабинет. Ключ показывается один раз — сохраните его в Orchestrator как Credential/Asset. Если ключ утёк — отзовите и создайте новый.

Связь с 1С

Проверяет OData всех облачных баз одним пользователем из секретов кабинета (ONEC_USER, ONEC_PASSWORD).

Запустить робота сейчас

Кнопка сразу запускает процесс в UiPath Orchestrator — без открытия Assistant.

Нужно один раз подключить UiPath к кабинету:
  1. cloud.uipath.com → Admin → External Applications → Add Application → «Confidential application», название «ESEP кабинет».
  2. Add scopes → Orchestrator API Access → Application scope(s): OR.Jobs, OR.Execution.Read → Save (вкладка Application scope(s), не User scope). Скопируйте App ID и App Secret.
  3. Orchestrator → папка с процессами → Manage access → Assign account/group → выберите приложение «ESEP кабинет», роль Automation User.
  4. supabase.com → проект esep-cabinet → Edge Functions → Secrets → добавьте UIPATH_CLIENT_ID (App ID) и UIPATH_CLIENT_SECRET (App Secret).

Запустить проверку

Фирмы, где робот готов к работе

Робот берёт задание при запуске процесса в Orchestrator: дату и список фирм он получает отсюда. По расписанию (6-го числа) без задания в очереди робот проверяет все фирмы на последний день прошлого месяца.
