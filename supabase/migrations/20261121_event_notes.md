# 21.11.2026 — комментарии к строкам отчётов (event_notes)

`public.event_notes(event_id, item_key, note, by_user, at)`, ключ строки — как у `event_marks` (Дт/Кт `dt|Название`, счета/доверенности/диагностика — ключ документа).
- RLS: читают участники фирмы, видящие робота.
- `public.set_event_note(p_event, p_key, p_note)` — пишет/обновляет/стирает (пустой текст); любой участник фирмы; только в свежей проверке (superseded_at is null); до 2000 знаков.
- `public.event_notes_of(p_events uuid[])` → `{event_id: {item_key: {cur:{note,at,who}, last:{note,at,who,ev_at}}}}`: cur — написан в этой проверке, last — последний написанный в любой прежней проверке того же робота у фирмы (ev_at — дата той проверки).
Кабинет: `evNotes`, `loadNotes(ids)` (грузится вместе с отметками), `noteCell(ev,key)` — прошлый только читать, новый — поле (сохраняется по уходу с поля или Ctrl+Enter); в прошлой проверке — только чтение. Печать/PDF/Excel — по галочке «с анализом и комментариями» / «с комментариями» (`F.an` у Дт/Кт, `F.nt` у списков, `mp-an` в печати по всем фирмам).
