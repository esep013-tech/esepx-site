# 20.11.2026 — bank_settings_and_rules (робот «Выписки банка»)
- public.bank_settings(company_id pk, settings jsonb) — настройки фирмы: post (проводить), salary (загружать ЗП и отчисления), own ('pp' | 'po' — свои переводы платёжным поручением или платёжным ордером), def_in / def_out (правило по умолчанию), off (отключённые общие правила). Запись — RPC bank_settings_set (владелец, главбух, оператор 1С, сопровождение, админ).
- public.bank_rules — правила разноски: company_id пустой = общее (меняет только админ), иначе правило фирмы. Условия: dir, knp (список через запятую), cp_bin, word; результат: doc (ppi/ppo/poi/poo/skip), op (вид операции 1С), cash_flow (название статьи ДДС). RPC bank_rule_save, bank_rule_delete.
- Чтение — RLS: участник фирмы или админ; общие правила видят все вошедшие.
- Засеяны общие правила (по разноске в базах Ирины) + «Взнос наличных» (331), «Снятие наличных» (341).
